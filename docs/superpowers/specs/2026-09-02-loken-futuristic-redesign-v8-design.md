# V8 LOKEN 未来主义整站视觉重构设计

## 目标

V8 将网站从现有“知识罗盘”视觉系统重构为一座未来知识展馆，并把网站公开品牌从 `TOGOS` 统一更名为 `LOKEN`。本版本只改变品牌、信息架构呈现、页面布局、字体、颜色和交互反馈，不改变论文、经典模型、个人文章和搜索的数据契约。

定时任务接入新版论文摘要流水线顺延至 V9。“跑得还快”在 V8 中完成正式视觉模板与空状态，但不接入地图服务、城市数据或照片管理能力。

V8 的成功标准不是“看起来更像科技产品”，而是让四类长期积累的内容看起来属于同一个人的知识系统，同时仍可快速浏览高密度论文数据和舒适阅读长文。

## 设计依据

参考图的可复用语言包括：

- 精确的模块网格与细边界；
- 大尺度主体与留白作为空间构件，不依赖装饰性巨型编号；
- 主视觉跨越多个网格，而不是被装进普通卡片；
- 黑白高反差、少量信号色和克制的控制文字；
- 不对称的信息密度，以及展览目录式导航。

V8 不复制参考图中的机器人、展览文案或具体构图，也不采用霓虹渐变、玻璃卡片、发光仪表盘等常见“科技后台”套路。

## 品牌

### 名称

- 所有网站可见品牌、页面标题、辅助文本和无障碍标签中的 `TOGOS` 改为 `LOKEN`。
- 仓库名、GitHub 地址、现有页面路径与数据文件名不在 V8 中更名，避免破坏部署、外部链接和历史深链。
- `README.md` 按项目规则保持不变。

### Logo 预留

- 桌面端品牌区预留 `32 × 32px` 图形 Logo 位，移动端为 `28 × 28px`。
- 正式 Logo 完成前，图形位显示简洁的 `LK` 占位符，旁边显示 `LOKEN` 字标。
- DOM 保留独立的图形位与字标，未来替换为 SVG 或图片时不改变导航尺寸、不引起布局跳动。
- V8 不生成正式 Logo；Logo 设计作为独立版本处理。

## 视觉系统

### 颜色

- `Void #0B0D0E`：全局黑墨、主导航和高对比区域。
- `Carbon #15181A`：深色层次和深色模式画布。
- `Gallery #F1F2EF`：主要浅色背景，避免纯白造成眩光。
- `White #FAFBF8`：正文、浮层和输入区域。
- `Grid #C9CCC7`：模块边界、表格分隔和地图网格。
- `Signal Blue #355CFF`：当前主题、选中节点、城市 Pin 和主要交互状态。
- `Live Mint #A8FFDF`：仅表示“运行正常、摘要完成”等实时成功状态，不作为装饰色。

深色模式保留相同语义：黑色成为画布，浅色成为正文，蓝色仍表示选中，薄荷色仍只表示成功。每个主题不分配独立品牌色，主题差异由编号、内容结构和主视觉机制承担。

### 字体

- 展示标题与拉丁字母：自托管 `Space Grotesk`，使用 600–700 字重和较紧字距。
- 中文标题与正文：`PingFang SC / Microsoft YaHei / Noto Sans CJK SC` 系统回退栈，避免引入体积过大的远程中文字体。
- 数据、日期、arXiv ID、坐标和快捷键：自托管 `IBM Plex Mono`。
- 不使用远程字体 CDN。字体文件与许可证放在站点资源目录，网络不可用时仍保持稳定版式。

字号层级：

- 主题页主标题：`clamp(2.6rem, 5vw, 4.75rem)`；
- 内容分区标题：`1.35–1.75rem`；
- 条目标题：`0.95–1.08rem`；
- 正文：`1rem / 1.72`，文章正文为 `1.0625rem / 1.82`；
- 工具与元数据：`0.6875–0.75rem` 等宽字体。

## 全局布局：模块标本馆

### 桌面端

```text
┌──────────────┬──────────────────────────────────────────────────┐
│ LOGO LOKEN   │                           [ 搜索文章… ]  THEME  │
├──────────────┼──────────────────────────────────────────────────┤
│ MENU         │ 主题名称、说明与必要统计                        │
│              ├──────────────────────────────────────────────────┤
│ 01 学习一个  │ 当前主题快速导航                    INDEX ☰     │
│ 02 身经百战  ├──────────────────────────────────────────────────┤
│ 03 谈笑风生  │ 主题主内容                         主题标本区   │
│ 04 跑得还快  │                                                  │
│              │                                                  │
└──────────────┴──────────────────────────────────────────────────┘
```

- 一级导航固定为约 `9.375rem` 的模块轨道，使用完整中文主题名与小号两位编号。
- 主题名称与说明只出现在正文顶部，不在二级导航重复显示。
- 现有常驻二级侧栏改为“上下文抽屉”：常用分类显示在正文顶部的水平上下文条中，完整目录通过 `INDEX ☰` 打开。
- 上下文抽屉保留折叠状态和键盘操作；折叠后不占正文宽度，打开后从内容左侧滑入或在宽屏中临时占位。
- 删除没有明确用户任务的 `EXHIBITION / INDEX / ABOUT` 顶部入口。全局顶部只保留常驻搜索框与深浅主题切换，品牌首页入口由左上角 LOKEN 承担。
- 删除所有主题标题区右上角的装饰性大编号，并将标题区高度收紧，让真实正文上移。

### 移动端

- 小于 `900px` 时，一级导航与上下文目录合并为全屏抽屉；顶部仅保留 Logo、当前主题、搜索和菜单。
- 小于 `600px` 时，搜索框占据顶部第二行，不折叠为弹窗或仅图标入口。
- 小于 `600px` 时，所有双栏内容变为单栏；主题标本排在首组真实内容之后，避免视觉装饰占满首屏。
- 主题切换、搜索和菜单触控目标不小于 `44 × 44px`。
- 论文表格继续在自身容器中横向滚动，页面本身不得横向溢出。

## 四个主题页面

### 01 学习一个：Paper Signals

页面任务是让读者快速判断今天新增了什么、属于哪个分类、是否已有本地摘要，并进入论文或摘要。

- 主标题区显示今日新增、历史总量和最近同步时间。
- 上下文条提供 Today、Image、Video、3D、Render、Depth 等入口。
- 论文继续使用高密度行列表，不改成卡片墙；arXiv ID、标题、分类、作者和摘要状态形成稳定列。
- 右侧区域初始可显示克制的信号状态；用户点击任一论文的“要点”后，该区域原位切换为论文要点阅读面板，不再打开摘要弹窗。
- 要点面板显示论文标题、分类、核心问题、方法、主要结论和原文入口；选中论文行具有明确状态，连续选择其他论文时原位更新内容。
- 桌面端要点面板保持在论文列表右侧并独立滚动；移动端则插入选中论文行之后，不使用遮挡内容的模态框或底部弹层。
- 要点加载失败时在同一区域说明失败原因并保留“打开原文”入口，不能清空当前论文上下文。
- `Live Mint` 只用于摘要已完成等成功状态；单篇摘要失败仍用清晰文字说明下一步。

### 02 身经百战：Model Archive

页面任务是理解经典模型的演进关系，并比较架构、目标函数和能力边界。

- 以时间轴作为首要导航，模型节点按年份与技术范式排列。
- 选中模型后，右侧显示抽象“结构标本”，正文区展示模型名称、组织、年份和技术摘要。
- 架构、训练目标与代表能力先以三项摘要呈现，详细比较表按需展开。
- FLUX 等现有页面路径与内容保持不变，只重构布局和视觉层级。
- 移动端时间轴允许横向滚动，并提供可见的当前位置提示。

### 03 谈笑风生：Field Notes

页面任务是浏览和阅读个人学习笔记、读书笔记与长期文章，同时理解内容来源但不暴露内部工作流。

- 首页采用编辑式文章流：精选文章占据主要版面，其余文章按类型、日期和阅读时间排列。
- 右侧“来源轨道”只展示 Notion、微信读书等公开可解释来源和文章数量，不展示私有路径、缓存或内部运行细节。
- 文章详情页使用更窄的正文版心；来源、发布日期和标签退为元数据。
- 代码块、公式和表格在需要时独立横向滚动，不扩大整页宽度。
- 空状态提供清晰的内容说明，不显示后台导入按钮。

### 04 跑得还快：City Memory

页面任务是通过地图确认去过的城市，并通过摄影回忆城市，而不是展示旅行统计仪表盘。

- V8 只实现视觉模板和空状态：世界地图网格、城市 Pin、右侧城市摄影位和图层控制均使用无真实数据的演示结构。
- 未来地图精度按城市级行政区划设计；缩放到城市后显示行政边界。
- 选中 Pin 后，右侧区域切换城市名称、坐标、到访信息和摄影入口，不使用遮挡地图的大型弹窗。
- 城市详情页预留照片接触表、时间与路线，但不在 V8 接入图片上传或地图服务。
- 用户尚未录入城市时，页面明确说明功能尚未开放，不伪造旅行数据。

## 搜索与交互

- 保留现有标题搜索和 `Ctrl/Cmd + K` 快捷键。
- 右上角直接显示搜索输入框，输入时在输入框下方展开结果面板；不再先点击按钮或打开搜索弹窗。
- 结果按四个主题分组，命中标题是第一视觉层级；Escape 关闭结果面板但保留输入内容，`Ctrl/Cmd + K` 直接聚焦搜索框。
- 二级目录展开、主题切换、搜索结果出现和论文要点切换使用 `160–220ms` 的单次位移或淡入。
- 不添加持续旋转、粒子背景、滚动入场或装饰性视差。
- `prefers-reduced-motion` 下关闭非必要动画。

## 技术边界

- 共享壳层仍由 `src/shared/site_shell.py` 生成，四类页面继续使用各自现有渲染器。
- 视觉令牌、响应式规则和主题模板集中在 `docs/assets/css/site.css`；避免为生成后的单页写内联补丁。
- 全局交互继续由 `site-shell.js`、`sidebar.js` 和 `search.js` 承担；不引入前端框架。
- 将品牌名定义在共享壳层的单一常量中，避免生成器各处硬编码。
- 现有 URL、搜索索引字段、JSON 数据结构、摘要发布流程和深链锚点不得改变。
- 生成的 `docs/*.html` 随构建器更新，不手工维护生成页。
- V8 不修改 `README.md`，不实现 V9 定时任务迁移，也不实现真实地图功能。

## 可访问性

- 所有按钮、主题入口、时间轴节点和搜索结果均支持键盘访问和可见焦点。
- 选中状态同时使用反色、文字权重和 `aria-current`，不能只依赖蓝色。
- 浅色与深色模式的正文、辅助文字和边界达到可辨识对比度。
- 上下文抽屉打开时正确管理焦点，Escape 可关闭并返回触发按钮。
- 无 JavaScript 时仍可访问一级导航、正文和页面内目录链接。

## 验证策略

按项目规则，V8 新增或修改的测试文件只在本地存在，完成后删除，不进入提交或 PR。验证包括：

- 共享壳层中 LOKEN、Logo 占位、四主题导航和上下文抽屉的结构断言；
- 四类生成器的主题标题、说明、深链和搜索索引回归；
- 常驻搜索框、搜索结果、论文要点面板、深浅主题、抽屉状态和键盘交互的 JavaScript 语法与行为检查；
- `1440 × 1000`、`1024 × 768` 与 `390 × 844` 三种视口截图检查；
- 长英文论文标题、中文长标题、空文章列表和无城市数据状态；
- Python 语法、全部现有构建、HTML 结构、JavaScript 语法与 `git diff --check`；
- 连续执行两次站点构建，第二次不得产生漂移。

## 验收标准

- 网站所有可见品牌均为 LOKEN，Logo 位尺寸稳定，正式 Logo 缺失时不出现破图。
- 四主题共享同一未来主义模块壳层，同时能通过 `01–04` 编号和主题标本快速区分。
- 顶部不存在 `EXHIBITION / INDEX / ABOUT` 等无明确任务的入口；搜索框无需额外点击即可输入。
- 所有主题标题区不显示装饰性大编号，正文起始位置较初版草图明显上移。
- 二级导航不重复主题名和说明，默认不挤压正文，仍可展开、折叠并记忆状态。
- 学习一个保持论文扫描效率，点击“要点”在右侧原位展示内容；身经百战突出时间轴；谈笑风生适合长文阅读；跑得还快呈现可信的未来地图空状态。
- 常驻搜索、深浅主题、论文要点面板、深链和现有数据生成行为不回归。
- 三种验收视口均无页面级横向溢出，内容表格只在自身容器滚动。
- 所有验证通过，临时测试和视觉伴侣目录不被提交，`README.md` 保持不变。

## 自我审查

- 文档没有未决占位项：正式 Logo 和真实地图被明确划入后续版本，不影响 V8 实施。
- 品牌更名仅限网站表现层，与仓库及路径稳定性不冲突。
- 四主题使用同一颜色体系，避免演变成四个割裂子站。
- 视觉张力集中在主题首页的标本区；高密度列表和长文详情明确回归可读性，不让参考图的展览构图损害实际使用。
- V8 范围只包含视觉与布局重构，V9 自动化迁移和后续地图功能保持独立故障域。
