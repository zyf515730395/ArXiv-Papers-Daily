[2608.20891] IMU-Free Body-Frame State Estimation with Sparse Scene Flow for Quadcopters

arXiv 原文

一句话结论

本文提出了一种无需惯性测量单元的纯视觉四旋翼机身状态估计系统，利用连续离散扩展卡尔曼滤波与稀疏场景流生成技术，在无 GPS 和外部基础设施依赖下实现了机身姿态、速度及重力估计。

解决的问题

现有视觉状态估计方法通常依赖惯性测量单元提供高频运动学约束或依赖全球定位系统实现世界坐标系下的全局定位，导致系统成本高或易受环境限制，本文旨在解决在无惯性传感器及外部基础设施依赖下，仅凭视觉信息实现鲁棒机身状态估计的问题。

创新点

  • 无需惯性测量单元的纯视觉四旋翼机身状态估计架构，摆脱对 GPS 及世界坐标系基础设施的依赖。
  • 设计基于连续离散扩展卡尔曼滤波的复合流形状态估计器，利用静止场景点作为隐式惯性参考。
  • 生成携带位置和速度信息的稀疏场景流，通过多视图全束调整联合估计深度与视差。
  • 实现空间自适应的点云密度分配，利用外部关注焦点优化区域覆盖。

[2608.20775] The four-dimensional Chamon code

arXiv 原文

一句话结论

本文提出了一种四维 Chamon 码，证实了其作为三维 Chamon 码四维推广的受限移动性激发特性，并基于其几何代数结构设计了高性能解码器。

解决的问题

现有研究对四维 Chamon 码的激发性质尚未深入探究，且缺乏能够利用其几何代数结构的高性能解码算法，导致无法充分验证其作为三维 Chamon 码四维推广的有效性。

创新点

  • 建立了四维 Chamon 码代数结构与四维周期晶格的对应关系，明确了物理量子比特和稳定子的几何分布
  • 证实了四维 Chamon 码支持类似三维 Chamon 码的三种受限移动性激发，验证了其作为四维推广的属性
  • 揭示了码的超平面对称性及投影诱导的二维 Toric 码结构特性
  • 提出了利用上述结构特性的两层解码算法，显著优于传统 BP-OSD 解码器

[2608.20759] DiGS-Avatar: Single-Image Animatable 3D Human Reconstruction via UV-Space Diffusion

arXiv 原文

一句话结论

DiGS-Avatar 提出了一种基于 UV 空间扩散的框架，通过师生架构和 3D 高斯原语解码，实现了高效且高保真的单图像可动画 3D 人体重建。

解决的问题

现有单图像 3D 人体重建方法常导致纹理过度平滑和几何不一致，且依赖多视图合成的扩散模型计算成本高并易产生视图不一致。

创新点

  • 将任务重构为基于 UV 空间的扩散潜变量补全任务，确保 3D 一致性由设计保证
  • 提出多视图教师 - 单视图学生框架，利用几何对齐的伪真实潜变量监督单视图扩散模型
  • 将推断出的潜变量作为鲁棒结构骨架，注入高层语义特征以恢复精细纹理细节而不破坏空间完整性
  • 将优化后的表示解码为 3D 高斯原语以支持快速动画生成

[2608.20748] Generating Multi-view Adversarial Examples for Visual Geometry Grounded Transformer

arXiv 原文

一句话结论

本文提出了一种名为 MVAP-G 的多视角对抗扰动生成器，能够在单次前向传递中生成跨视角一致的不可感知扰动，从而显著降低 VGGT 模型的性能。

解决的问题

传统对抗扰动需要昂贵的每场景优化，而通用对抗扰动（UAPs）依赖单一静态模式，无法有效攻击 VGGT 这类统一多视图输入的 3D 基础模型。

创新点

  • 提出 MVAP-G，能在单次前向传递中生成跨视角一致的对抗扰动，无需迭代优化
  • 设计了跨视角对抗对齐机制，确保在不同场景下扰动的多视图一致性
  • 生成的扰动具有不可感知性，同时显著降低 VGGT 性能
  • 开创了针对 3D 基础模型的多视角对抗攻击研究，揭示了严重的安全漏洞

[2608.20740] VisTa3D: A Dataset and Benchmark for Thin Object Reconstruction from Vision, Tactile, and 3D Point Clouds

arXiv 原文

一句话结论

VisTa3D 提出了首个融合视觉、测距和触觉数据的薄物体重建数据集与基准，揭示了现有模型在薄物体场景下重建保真度低的问题，并引入基线模型以验证触觉数据对形状恢复的辅助作用。

解决的问题

现有基于视觉或测距数据的 3D 重建模型在处理薄物体时重建保真度较低，主要归因于薄物体在图像和点云中占据空间小，导致像素和采样点稀疏，且现有基准数据集缺乏针对薄结构的关注，高分辨率传感器又面临成本与计算资源的限制。

创新点

  • 构建了首个包含同步 RGB 图像、深度图及触觉响应图的薄物体重建数据集 VisTa3D。
  • 提出了首个融合视觉、测距和触觉数据的 3D 重建模型作为基线。
  • 建立了针对薄物体重建的基准测试，验证了现有模型在薄结构上的低保真度问题。
  • 引入触觉数据以提供局部形状和变形信息，辅助薄物体的重建。

[2608.20720] AffordAny: Open-World 3D Affordance Grounding from Monocular RGB Images via Vision-Language-Guided Geometric Reasoning

arXiv 原文

一句话结论

AffordAny 利用单目 RGB 图像构建大规模文本条件 3D 部件监督，结合冻结 VLM 引导解码器与伪标签自训练，实现了无需预建 3D 资产的开放世界 3D 功能区域定位。

解决的问题

现有方法通常假设训练和推理时均有预建的 3D 几何信息，限制了从原始 RGB 图像部署的能力；同时缺乏具有真实图像来源和 3D 部件级监督的大规模数据集，且基于 CLIP 的文本编码方法对指令改写较为脆弱，难以满足开放世界的自由语言查询需求。

创新点

  • 提出自动化数据构建流程，从 LVIS 数据集生成大规模文本条件 3D 部件级监督基准，覆盖 473 个类别。
  • 设计 VLM 引导的跨模态 3D 功能解码器，融合冻结 Cosmos-2B 特征与 3D 点云几何，无需微调 VLM 主干。
  • 引入最小扰动伪标签自训练策略，利用训练好的解码器生成新物体标签，显著改善类别级泛化能力。

[2608.20699] ArtiMo: Agent-Driven Articulated Mesh Animation

arXiv 原文

一句话结论

本文提出了一种名为 ArtiMo 的零样本智能体驱动框架，通过结合大语言模型、视觉语言模型与 URDF 运动约束，实现了满足运动学有效性和因果正确性的文本引导式关节化网格动画生成。

解决的问题

现有的文本驱动 4D 动画方法通常忽略明确的关节结构和运动限制，难以处理受关节轴、部分依赖和因果顺序约束的运动；同时 URDF 仅定义运动能力而未指定特定动作下的运动逻辑，且缺乏针对该任务的专用训练数据和监督信号。

创新点

  • 提出零样本智能体框架，协同 VLM 的语义推理与 LLM 的运动规划能力，在 URDF 约束下生成运动轨迹。
  • 引入视觉自改进机制，将生成的动画渲染为关键帧供 VLM 诊断错误并迭代修正运动计划。
  • 构建了包含 21 个类别和 225 个动作序列的关节化网格动画新基准数据集，包含因果关系标注。

[2608.20691] Bridging Language and Spherical Space: Object-Centric Control for Text-to-Panorama Generation

arXiv 原文

一句话结论

本文提出 PanoCtrl 框架，通过结构化对象级表示连接自然语言与球面全景空间，实现了具有准确方向控制的可控文生全景生成。

解决的问题

现有文生全景方法依赖隐式空间推理，难以在复杂场景中准确落地物体级方向描述；引入显式布局虽能辅助控制，但依赖人工指定降低了语言交互灵活性，且现有方法难以适配球面几何与 ERP 表示带来的空间对齐挑战。

创新点

  • 提出 PanoCtrl 框架，明确连接自然语言与球面全景空间以实现更准确的方向落地
  • 设计 PanoParse 模块，将文本描述转换为包含语义类别和球面边界视场参数的结构化对象级条件
  • 设计 PanoControl 模块，通过对象感知注意力机制和空间残差增强将语义及空间引导注入扩散过程
  • 构建 PanoGround 数据集，提供物体级球面注释并建立基准，验证了方法在空间对齐和图像质量上的最先进水平

[2608.20659] Lift, Associate, and Fuse: A Decision-Centric Framework for 2D-to-3D Foundation Model Transfer

arXiv 原文

一句话结论

本文提出了一种名为 LAF 的以决策为中心的框架，将 2D 到 3D 的迁移系统分解为生成、关联、协调、融合和持久化/查询五个算子，旨在通过标准化持久化载体的契约来诊断现有系统的不可逆失败，并为未来智能体提供可修订的 3D 感知规范。

解决的问题

现有方法通常按任务或表示形式对 2D 到 3D 分割系统进行分类，这种分类虽然便于检索，但无法诊断系统跨视图的连贯性。现有分类掩盖了关键决策过程，如图像证据的锚定、观测是否属于同一身份、语义与粒度冲突的处理以及信息的融合与保留，导致缺乏对系统一致性的有效评估标准。

创新点

  • 提出 LAF 框架，将迁移系统定义为生成、关联、协调、融合和持久化/查询五个算子。
  • 定义了持久化载体的明确契约，涵盖空间支持、语义状态、身份状态、不确定性及溯源等属性。
  • 建立了结构化审计协议，应用于 161 个系统以揭示关联不等同于身份等四项共性特征。
  • 提供了一种表示无关的比较方法，用于诊断失败并规范未来的 3D 感知设计。

[2608.20639] MV2GF: Multi-view Pedestrian Detection with a Visual Geometric Foundation Model

arXiv 原文

一句话结论

本文提出 MV2GF 方法，利用视觉几何基础模型融合任务特征与通用几何特征，有效解决了多视图行人检测中面对未见相机配置时几何捕捉困难及模型依赖训练畸变模式的问题，实现了更好的泛化性能。

解决的问题

现有 MVPD 方法采用将 2D 图像特征投影到 3D 世界空间的统一框架，导致模型在面对未见过的相机配置时难以捕捉准确的跨视图视觉几何，且检测模型高度依赖于训练期间产生的图像特征投影畸变模式，从而限制了其在多样化场景下的泛化能力。

创新点

  • 利用视觉几何基础模型在捕捉跨视图视觉几何和预测 3D 属性方面的强泛化能力
  • 融合任务特定特征与基础模型提取的通用几何特征，以有效捕捉未见相机配置下的视觉几何
  • 利用基础模型预测的 3D 点地图将图像特征像素投影到适当的 3D 位置，防止检测模型依赖训练畸变模式

[2608.19769] AsymFeX: A Symmetry-Driven Framework for Ischemic Stroke Segmentation Across Imaging Modalities and Stroke Stages

arXiv 原文

一句话结论

本文提出了一种名为 AsymFeX 的对称驱动框架，通过几何倾斜校正与局部跨半球注意力机制，实现了跨影像模态和卒中阶段的急性缺血性卒中病灶高精度自动分割，并在多个数据集上验证了其性能。

解决的问题

现有对称感知方法存在计算冗余、2D 局限、未校正头倾角导致解剖错位、依赖全脑切片不兼容现代框架以及缺乏跨模态评估与不确定性分析等不足，难以满足临床快速决策需求。

创新点

  • 提出两阶段 3D 分割流程，集成几何倾斜校正步骤以确保跨半球比较的解剖有效性，并兼容 nnU-Net 框架。
  • 设计 AsymFeX 模块，结合 3D 局部跨半球注意力、差异估计与双尺度门控，限制比较范围至局部邻域。
  • 验证了该对称驱动设计在急性至慢性卒中成像连续体（CT 灌注与 MRI）上的跨模态泛化能力。
  • 提供了涵盖误差不确定性和校准分析的全面不确定性量化评估，以衡量临床部署下的预测可靠性。
