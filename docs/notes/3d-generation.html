[2608.20891] IMU-Free Body-Frame State Estimation with Sparse Scene Flow for Quadcopters

arXiv 原文

一句话结论

本文提出了一种无需 IMU 且仅依赖视觉的 X 型四旋翼机身状态估计系统，通过在机身框架内运行连续 - 离散扩展卡尔曼滤波并利用静止场景点作为隐式惯性参考，实现了在无 GPS 及世界坐标系基础设施下的姿态、速度与场景流估计。

解决的问题

现有飞行器状态估计方法通常严重依赖惯性测量单元（IMU）或全球定位系统（GPS）等辅助传感器，而在缺乏惯性参考且无外部定位辅助的纯视觉场景下，难以有效解决重力估计、速度解算及运动扰动抑制问题，导致机身框架状态估计的稳定性与鲁棒性受限。

创新点

  • 无需惯性传感器的纯视觉机身框架状态估计架构，利用静止场景点作为隐式惯性参考以替代 IMU
  • 基于复合流形上的连续 - 离散扩展卡尔曼滤波（EKF），结合 Chi-squared 门控机制筛选静止点以优化状态更新
  • 生成携带位置、速度及联合协方差的稀疏 3D 点云，通过 4 视图 bundle adjustment 联合估计位置与速度
  • 空间自适应的点云密度分配，利用外部关注点引导资源分配，实现感兴趣区域密集覆盖

[2608.20775] The four-dimensional Chamon code

arXiv 原文

一句话结论

本文提出了一种四维 Chamon 码，通过建立其与四维晶格的代数结构对应关系，证实了该码支持受限移动性激发，并将其视为三维 Chamon 码的四维推广；同时利用超平面对称性和投影诱导的二维 Toric 码结构，提出了一种两层解码策略，在解码精度上显著优于 BP-OSD 解码器。

解决的问题

现有的四维 Chamon 码研究尚未深入探讨其激发性质，且缺乏能够利用其几何和代数结构的高性能解码策略。现有的解码方法未能有效结合该码的内在几何与代数特性，导致解码精度不足，无法充分挖掘 Fracton 模型在量子存储中的潜力。

创新点

  • 建立了四维 Chamon 码的代数结构与四维周期性晶格之间的对应关系，明确了物理量子比特和稳定子的几何分布。
  • 分析了四维 Chamon 码的激发性质，证实了其支持类似于三维 Chamon 码的三种受限移动性激发，验证了其作为三维模型四维推广的地位。
  • 揭示了四维 Chamon 码的超平面对称性和投影诱导的二维 Toric 码结构。
  • 提出了一种针对四维 Chamon 码的两层解码算法，将原始解码问题分解为多个独立且可并行的子问题，显著提升了解码精度。

[2608.20759] DiGS-Avatar: Single-Image Animatable 3D Human Reconstruction via UV-Space Diffusion

arXiv 原文

一句话结论

DiGS-Avatar 通过 UV 空间扩散与师生框架，实现了高效、一致且可动画化的单图像 3D 人体重建，在 0.71 秒内生成高质量化身。

解决的问题

现有单图像 3D 人体重建常导致纹理过平滑和几何不一致，且依赖多视图合成先验的扩散模型存在计算昂贵和视图不一致的问题。

创新点

  • 将任务重构为高效的基于 UV 空间的扩散隐变量补全任务，从设计层面确保 3D 一致性
  • 引入多视图教师 - 单视图学生框架，利用几何对齐伪真值隐变量监督单视图扩散模型
  • 将推断隐变量作为结构骨架，注入高层语义特征以恢复精细纹理细节而不破坏空间完整性
  • 将优化后的表示解码为 3D Gaussian primitives 以支持高质量重建与零样本泛化

[2608.20748] Generating Multi-view Adversarial Examples for Visual Geometry Grounded Transformer

arXiv 原文

一句话结论

本文提出了 MVAP-G，一种针对 Visual Geometry Grounded Transformer（VGGT）的多视角对抗扰动生成器，能够在单次前向传递中生成跨视角一致且不可感知的扰动，无需迭代优化即可显著降低 VGGT 性能，揭示了 3D 基础模型的安全漏洞。

解决的问题

传统对抗攻击需要昂贵的每场景优化，而通用对抗扰动（UAPs）依赖单一静态模式，无法有效攻击具有大规模参数的 VGGT 等现代 3D 基础模型，且大型模型对朴素对抗扰动表现出鲁棒性，使得现有方法难以生效。

创新点

  • 提出 MVAP-G 生成器，实现在单次前向传递中生成跨多视角的一致对抗扰动
  • 设计跨视角对抗对齐机制，确保不同场景下扰动的一致性
  • 无需推理阶段的迭代优化，显著降低 VGGT 的性能表现
  • 开创性地针对 3D 基础模型进行多视角对抗攻击，揭示其严重脆弱性

[2608.20740] VisTa3D: A Dataset and Benchmark for Thin Object Reconstruction from Vision, Tactile, and 3D Point Clouds

arXiv 原文

一句话结论

VisTa3D 提出了首个针对薄物体重建的视觉 - 触觉 -3D 点云多模态数据集与基准，揭示了现有方法在薄物体上表现不佳的问题，并通过引入触觉响应数据及首个视觉 - 深度 - 触觉联合重建模型，验证了多模态融合在提升薄物体重建保真度方面的有效性。

解决的问题

现有的 3D 重建模型在处理薄物体时表现欠佳，主要源于薄物体在 RGB 图像中占据像素极少，且在深度传感器返回中信号稀疏，导致微小传感器运动易引发遮挡或去遮挡，丢失跨视角对应关系从而降低重建保真度；此外，现有基准数据集缺乏对薄结构的专门关注，且高分辨率传感器在实际成本与计算资源上不可行。

创新点

  • 构建了首个针对薄物体的多模态数据集 VisTa3D，集成同步 RGB 图像、深度图、触觉响应图及地面真值激光扫描数据，涵盖 387 个场景与 70 个薄物体。
  • 建立了薄物体重建基准，证实现有视觉与深度感知模型在薄结构场景下普遍存在低保真度问题。
  • 提出了首个视觉 - 深度 - 触觉（Visual-Range-Tactile）联合 3D 重建模型作为基线，验证了触觉数据在提升重建质量方面的潜力。

[2608.20720] AffordAny: Open-World 3D Affordance Grounding from Monocular RGB Images via Vision-Language-Guided Geometric Reasoning

arXiv 原文

一句话结论

本文提出 AffordAny 框架，通过单目 RGB 图像结合冻结视觉语言模型（VLM）引导的解码器与伪标签自训练，实现了无需预建 3D 资产的开放世界 3D 功能区域定位，在未见物体与类别上实现了显著的性能提升。

解决的问题

现有方法通常依赖预建的物体中心 3D 几何和封闭功能本体，限制了从原始 RGB 观测的部署；同时，具有真实图像来源和 3D 部件级监督的可扩展数据集稀缺，且基于 CLIP 的文本编码对指令变体敏感，难以适应开放世界的长尾物体和自由形式语言指令。

创新点

  • 自动化数据构建流水线：基于 LVIS 数据集，结合 SAM 3D 单目重建、LLM 引导部件发现及多视图标注融合，生成大规模文本条件 3D 部件监督基准。
  • 视觉语言引导解码器：利用冻结的 Cosmos-2B 特征，通过空间投影注入、指令条件语义压缩及双向几何语义交互，实现无需微调 VLM 主干的跨模态 3D 功能定位。
  • 伪标签自训练策略：采用最小扰动训练和后验 Platt 校准，利用训练好的解码器为未见对象生成标注，显著提升类别级泛化能力且无需额外人工标注。
  • 系统化泛化评估协议：分别针对未见物体、未见类别及未见指令变体设计评估，全面验证开放世界下的鲁棒性。

[2608.20699] ArtiMo: Agent-Driven Articulated Mesh Animation

arXiv 原文

一句话结论

ArtiMo 提出了一种零样本代理驱动框架，通过结合 LLM/VLM 的推理规划能力与 URDF 的运动学约束，实现了无需微调的文本引导式可动网格动画生成，并构建了包含 21 类物体的新基准数据集。

解决的问题

现有基于数据的网格动画方法缺乏特定任务数据和显式关节监督，难以应用于可动对象场景；而现有的文本驱动 4D 动画方法通常忽略显式的关节结构，无法处理由关节轴、运动限制、部件依赖及因果顺序支配的运动，且 URDF 格式仅定义部件运动能力而无法指定特定动作下的因果传播与操作顺序。

创新点

  • 提出零样本代理驱动框架，协同 URDF 运动学约束与 VLM/LLM 的语义推理能力，无需模型微调即可生成符合物理约束的运动。
  • 引入视觉自我改进机制，通过渲染关键帧和运动提示让 VLM 诊断并修正错误，实现迭代优化运动正确性。
  • 构建了涵盖 21 类可动对象的新基准数据集，包含因果关系的运动标注以支持复杂交互评估。
  • 实现了从文本到 URDF 关节轨迹的因果转换，准确识别被操作部件、关节影响及运动传播顺序。

[2608.20691] Bridging Language and Spherical Space: Object-Centric Control for Text-to-Panorama Generation

arXiv 原文

一句话结论

本文提出 PanoCtrl，一种面向可控文本到全景生成的以物体为中心的框架，通过 PanoParse 将自然语言转化为结构化物体级球形条件，并利用 PanoControl 将语义与空间引导注入扩散 Transformer，结合新构建的 PanoGround 数据集，有效解决了语言方向与球形空间对齐问题，在空间对齐和图像质量上实现了最先进的性能。

解决的问题

现有文本到全景生成方法主要依赖隐式空间推理，难以在复杂的球形全景场景中忠实定位物体级方向描述，导致物体错位或空间不一致。引入显式布局虽可行，但需要手动指定空间条件，降低了语言交互的灵活性，且现有针对透视图像的可控生成方法难以直接应用于存在 ERP 畸变和球形环绕连续性的全景空间，导致语言驱动的方向控制在以观察者为中心的球形空间中难以实现。

创新点

  • 提出 PanoCtrl 框架，通过结构化物体级表示显式连接自然语言与球形全景空间，实现更准确的方向定位。
  • 设计 PanoParse 模块，将文本描述转换为包含语义类别和 BFoV 参数的结构化物体级球形条件。
  • 开发 PanoControl 机制，通过物体感知注意力和空间残差增强将语义与空间引导注入扩散 Transformer 中。
  • 构建 PanoGround 数据集，提供物体级球形标注，并建立基准测试以验证方法在空间对齐和图像质量上的 SOTA 性能。

[2608.20659] Lift, Associate, and Fuse: A Decision-Centric Framework for 2D-to-3D Foundation Model Transfer

arXiv 原文

一句话结论

本文提出了名为 LAF 的决策中心框架，将 2D 基础模型向 3D 分割的迁移过程形式化为生成、关联、协调、融合及持久化查询五个算子，旨在通过定义持久化载体的显式合同与决策追踪协议，实现跨系统比较、不可逆故障诊断及未来 3D 感知规范。

解决的问题

现有方法通常按任务类型（如语义、实例分割）或表示形式（如点云、NeRF、3D Gaussian Splatting）对 2D 基础模型向 3D 分割的预测转移进行分类，这种分类掩盖了决定系统跨视图一致性的关键决策过程，例如图像证据的锚定位置、观测何时被识别为同一实体、语义与粒度冲突的处理及信息融合机制；此外，现有的任务或表示标签仅适用于检索，无法有效诊断为何使用相同生成器和重建技术的系统可能在身份建立时机、信息保留状态及不可逆证据丢弃点存在显著差异。

创新点

  • 提出决策中心框架 LAF，将 2D 到 3D 转移形式化为生成、关联、协调、融合和持久化查询五个算子
  • 定义持久化载体的显式合同，明确其空间支持、语义与身份状态、不确定性、溯源及支持的操作
  • 建立结构化审计协议，实现对 161 个涵盖点、场、高斯、对象、图及记忆载体的系统进行表示无关的比较与不可逆故障诊断
  • 揭示决策追踪中的关键属性，指出关联不等同于身份建立，且评估指标需结合具体阶段与完整成本账本才有意义

创新点

  • 引入视觉几何基础模型 (Visual Geometric Foundation Model) 以增强在多样相机配置下捕捉跨视角视觉几何的能力
  • 融合任务特定特征与基础模型提取的通用几何特征，提升对未见相机配置的适应性
  • 利用基础模型预测的 3D 点图将图像特征像素投影至准确 3D 位置，避免对训练畸变模式的依赖

[2608.19769] AsymFeX: A Symmetry-Driven Framework for Ischemic Stroke Segmentation Across Imaging Modalities and Stroke Stages

arXiv 原文

一句话结论

AsymFeX 提出了一种两阶段 3D 分割框架，通过几何倾斜校正和局部跨半球注意力机制，在非对比 CT 上实现了缺血性卒中病灶的高效分割，并在多种模态和时间点上验证了泛化能力。

解决的问题

现有基于对称性的自动分割方法存在局限：通常在全脑或半球范围内进行注意力计算导致计算成本高，局限于 2D 无法捕捉体素特征，未校正头部倾斜导致对比区域非真实解剖对应，且依赖全脑切片输入难以兼容 nnU-Net 等基于补丁的框架，此外多数研究仅评估单一模态或时间点且缺乏可靠性度量。

创新点

  • 两阶段 3D 分割流程集成几何倾斜校正步骤，确保跨半球比较具有解剖学有效性
  • 提出 Asymmetric Feature Extraction (AsymFeX) 模块，结合局部 3D 跨半球注意力、差异估计和双尺度门控，限制比较范围至体素真实解剖对应点的局部邻域
  • 框架兼容 nnU-Net 及基于补丁的采样策略，解决了现有对称性方法对全脑切片输入的依赖
  • 实现了跨成像模态（NCCT/MRI）及卒中时间点的泛化验证，并包含不确定性量化以评估临床可靠性
