[2608.20891] IMU-Free Body-Frame State Estimation with Sparse Scene Flow for Quadcopters

arXiv 原文

一句话结论

本文提出了一种无需 IMU 的 X 型四旋翼机视觉状态估计系统，通过结合连续 - 离散 Extended Kalman Filter (EKF) 与 sparse scene flow 生成，实现了仅依赖 stereo images 和 motor thrust commands 的 body frame 状态估计，并输出用于下游 world model 的 sparse 3D point cloud。

解决的问题

现有四旋翼状态估计方法通常依赖惯性测量单元（IMU）或全球定位系统（GPS）等外部基础设施，但在无惯性传感器且无世界坐标系先验的场景下，纯视觉状态估计难以解决 body frame 下位姿与速度解算的鲁棒性问题，且传统方法难以同时提供携带运动信息的 sparse scene flow。

创新点

  • 构建无需 IMU 的纯视觉 X 型四旋翼状态估计系统，仅利用同步 stereo images 与 motor thrust commands 输入。
  • 提出基于 composite manifold state 的连续 - 离散 Extended Kalman Filter (EKF)，利用 stationary scene points 作为隐式惯性参考估计 pose 与 velocity。
  • 采用 4-view full bundle adjustment 生成携带 per-point position 与 velocity 的自适应 sparse 3D point cloud。
  • 设计 spatially adaptive 点云密度，通过 external focus point 控制关注区域分配。

[2608.20775] The four-dimensional Chamon code

arXiv 原文

一句话结论

本文提出了一种 4D Chamon 码，通过建立其代数结构与 4D 晶格的对应关系并揭示超平面对称性，设计了基于几何代数结构的两层解码策略，显著优于 BP-OSD 解码器。

解决的问题

现有的 4D Chamon 码研究尚未深入探讨其激发性质，且缺乏能够利用其几何和代数结构的高性能解码算法，导致无法充分证明其作为 3D Chamon 码 4D 推广形式的有效性及实际纠错性能。

创新点

  • 建立了 4D Chamon 码的代数结构与 4D 周期晶格之间的对应关系，明确了物理 qubits 和 stabilizers 的几何分布。
  • 分析了 4D Chamon 码的激发性质，证明其支持三种受限移动激发，验证了其作为 3D Chamon 码 4D 推广形式的物理特征。
  • 揭示了该码的超平面对称性和投影诱导的 2D toric-code 结构，并据此提出了一种分解为独立并行子问题的两层解码算法。

[2608.20759] DiGS-Avatar: Single-Image Animatable 3D Human Reconstruction via UV-Space Diffusion

arXiv 原文

一句话结论

论文提出 DiGS-Avatar，通过 UV-space Diffusion 将单图像 3D 人体重建重构为高效的 UV-latent 补全任务，从设计层面确保 3D 一致性，并在 0.71 秒内生成高保真、可动画的 3D 人体。

解决的问题

现有单图像 3D 人体重建方法常面临纹理过平滑与几何不一致的问题，且基于扩散模型的方法往往依赖多视图合成作为 3D 重建先验，导致计算开销大且易产生视图不一致性。

创新点

  • 提出基于 UV-space Diffusion 的任务重构，将单图像重建转化为高效的 UV-latent 补全任务，从设计层面确保 3D 一致性
  • 设计多视图教师 - 单视图学生框架，利用几何对齐的伪真值 latents 监督单视图扩散模型，解决结构捕捉问题
  • 将推断出的 latent 作为鲁棒结构骨架，注入高层语义特征以恢复精细纹理，避免破坏空间完整性
  • 将优化表示解码为 3D Gaussian primitives，实现快速生成可动画的 3D 人体

[2608.20748] Generating Multi-view Adversarial Examples for Visual Geometry Grounded Transformer

arXiv 原文

一句话结论

本文提出 MVAP-G，一种多视角对抗扰动生成器，能在单次前向传播中产生跨视角一致且不可察觉的扰动，显著削弱 VGGT 的 3D 重建性能。

解决的问题

现有对抗攻击方法在面对 VGGT 这类高性能 3D 基础模型时存在局限，传统方法需要昂贵的逐场景优化，而通用对抗扰动（UAPs）依赖单一静态模式无法有效攻击多视角模型，且缺乏针对多视角一致性的攻击机制，难以在无需迭代优化的情况下破坏模型性能。

创新点

  • 提出 MVAP-G 多视角对抗扰动生成器，支持单次前向传播生成跨视角一致扰动
  • 设计跨视角对抗对齐机制（cross-view adversarial alignment mechanism）以确保不同场景下的扰动一致性
  • 无需迭代优化即可显著降低对抗攻击的计算成本并削弱 VGGT 性能

[2608.20740] VisTa3D: A Dataset and Benchmark for Thin Object Reconstruction from Vision, Tactile, and 3D Point Clouds

arXiv 原文

一句话结论

本文提出了 VisTa3D 数据集与基准，并引入了首个视觉 - 深度 - 触觉联合的 3D 重建基线模型，有效缓解了现有方法在处理薄物体时因观测稀疏导致的低保真度问题。

解决的问题

现有最先进的 3D 重建模型在薄物体上表现不佳，主要原因是薄物体在 RGB 图像中像素占比小且在点云中空间有限，导致深度传感器回波稀疏；此外，有限的传感器分辨率与采样率易引发遮挡与对应点丢失，而高分辨率传感器又面临成本与计算资源限制，且现有基准数据集缺乏针对薄结构的专项评估。

创新点

  • 构建了首个包含同步 RGB、深度、触觉响应图及激光扫描真值的薄物体数据集 VisTa3D，覆盖 387 个场景与 70 个薄物体。
  • 提出了首个融合视觉、深度与触觉信息的 3D 重建基线模型，验证了触觉数据对提升薄物体重建保真度的有效性。
  • 揭示了触觉响应图能提供局部形状与形变信息，弥补了视觉与范围数据在薄物体表征上的不足。

[2608.20720] AffordAny: Open-World 3D Affordance Grounding from Monocular RGB Images via Vision-Language-Guided Geometric Reasoning

arXiv 原文

一句话结论

本文提出了 AffordAny 框架，通过单目 RGB 图像构建大规模文本条件 3D affordance 监督，结合冻结 VLM 引导的解码器与伪标签自训练策略，实现了无需预建 3D 资产的开放世界 3D affordance grounding，显著提升了未见类别与指令的泛化性能。

解决的问题

现有方法通常假设预建物体中心 3D 几何可用且依赖封闭的 affordance 本体论，限制了从原始 RGB 观察的部署；同时，具有真实图像来源和 3D 部件级监督的可扩展数据集稀缺，且基于 CLIP 或哈希嵌入的文本编码方法对指令同义改写较为脆弱。

创新点

  • 自动化数据构建流程，从 LVIS 数据集出发利用 SAM 3D 和 LLM 生成大规模文本条件 3D affordance 监督基准。
  • 提出 VLM 引导的跨模态 3D affordance 解码器，通过投影注入和双向交互融合冻结 Cosmos-2B 特征与 3D 点云几何。
  • 引入最小扰动伪标签自训练策略配合 Platt 校准，在不增加人工标注的情况下显著提升类别级泛化能力。
  • 设计了涵盖未见物体、未见类别和未见指令同义改写的系统性评估协议。

[2608.20699] ArtiMo: Agent-Driven Articulated Mesh Animation

arXiv 原文

一句话结论

本文提出了 ArtiMo，一种 zero-shot 智能体驱动框架，通过协同 URDF 运动学约束与 VLM/LLM 的推理规划能力，在无微调条件下实现了满足运动学有效性及因果关系的文本引导关节化网格动画，并在 21 个类别的新基准测试中显著优于现有基线。

解决的问题

现有文本驱动的 4D 动画方法通常忽略显式的关节化结构，难以处理由关节轴、限位及部件依赖支配的运动；同时，结构化资产格式如 URDF 仅定义了部件如何运动，却未说明针对特定动作应如何运动，缺乏对操作部件、运动传播及因果关系的理解，且缺乏任务特定的训练数据与显式关节监督。

创新点

  • 提出 ArtiMo zero-shot 智能体框架，协同 URDF 运动学约束与 VLM/LLM 的推理能力，实现无需微调即可生成运动学有效且因果正确的动画。
  • 引入视觉自改进机制，将生成的动画渲染为关键帧和运动提示，利用 VLM 诊断错误并迭代修正运动计划以提升正确性。
  • 构建包含 21 个关节化物体类别及因果关系标注的新基准数据集，涵盖 225 个注释运动序列以支持评估。

[2608.20691] Bridging Language and Spherical Space: Object-Centric Control for Text-to-Panorama Generation

arXiv 原文

一句话结论

本文提出了 PanoCtrl 框架，通过结构化对象级表示显式连接自然语言与球面全景空间，实现了可控文本转全景生成的空间对齐与图像质量的最先进性能。

解决的问题

现有文本转全景方法依赖隐式空间推理，难以在复杂场景中忠实定位物体级方向描述，存在语言指定方向与 ERP 空间表示之间的根本差距；引入显式布局虽可缓解对齐问题，但受限于欧几里得坐标设计难以适配球面几何，且降低了语言交互的灵活性。

创新点

  • 提出 PanoCtrl 框架，通过结构化对象级表示显式连接自然语言与球面全景空间，实现更准确的方向定位。
  • 设计 PanoParse 模块，将文本描述转化为包含语义类别和 BFoV 参数的结构化球面对象条件。
  • 开发 PanoControl 机制，通过对象感知注意力与空间残差增强将语义和空间指导注入 diffusion Transformer。
  • 构建 PanoGround 数据集，提供物体级球面标注以支持可控全景生成基准测试。

[2608.20659] Lift, Associate, and Fuse: A Decision-Centric Framework for 2D-to-3D Foundation Model Transfer

arXiv 原文

一句话结论

论文提出了 Lift, Associate, and Fuse (LAF) 框架，将 2D 到 3D 基础模型迁移表示为五个操作符，通过定义持久化载体的显式契约与结构化审计协议，实现了表示无关的系统比较、不可逆失败诊断及可修订的 3D 感知规范。

解决的问题

现有方法通常依据任务标签或表示形式（如 point cloud、3D Gaussian Splatting）进行分类，这种分组掩盖了决定系统跨视图一致性的关键决策过程，导致正确预测无法自动形成连贯的 3D 分割，且现有分类标签对于诊断身份建立时机、跨视图证据融合及状态保留等核心矛盾缺乏能力。

创新点

  • 提出决策中心化框架，将迁移系统抽象为 Generate、Associate、Reconcile、Fuse 和 Persist/Query 五个操作符。
  • 定义持久化载体的显式契约，涵盖空间支持、语义状态、身份状态、不确定性及溯源等属性。
  • 提供结构化审计协议以识别证据变为不可恢复的第一阶段，揭示关联不等于身份等关键属性。

[2608.20639] MV2GF: Multi-view Pedestrian Detection with a Visual Geometric Foundation Model

arXiv 原文

一句话结论

MV2GF 利用视觉几何基础模型融合任务特征与通用几何特征，并通过 3D pointmaps 消除训练依赖，显著提升了 Multi-view Pedestrian Detection 在未见相机配置下的泛化能力。

解决的问题

现有 Multi-view Pedestrian Detection 方法虽采用统一框架将 2D 图像特征投影至 3D 世界空间，但在未见相机配置下难以捕捉准确的跨视图视觉几何，且因图像特征投影导致检测模型高度依赖训练时的畸变模式，泛化能力受限。

创新点

  • 提出 MV2GF 框架，利用视觉几何基础模型（Visual Geometric Foundation Model）增强跨视图视觉几何的捕捉能力。
  • 融合任务特定特征与基础模型提取的通用几何特征，提升在多样化相机配置下的几何感知。
  • 利用基础模型预测的 3D pointmaps 将图像特征像素投影至准确 3D 位置，消除检测模型对训练畸变模式的依赖。
  • 在未见相机配置（unseen camera configurations）下展现出优于现有方法的泛化性能。

[2608.19769] AsymFeX: A Symmetry-Driven Framework for Ischemic Stroke Segmentation Across Imaging Modalities and Stroke Stages

arXiv 原文

一句话结论

本文提出 AsymFeX 框架，通过两阶段 nnU-Net 兼容的 3D 分割流程结合几何倾斜校正与局部跨半球 attention 机制，在非对比 NCCT 模态下实现急性缺血性卒中病变的高效精准分割，在 AISD 数据集上显著超越现有最先进方法并验证了跨模态泛化性与可靠性。

解决的问题

现有深度学习方法在处理非对比 NCCT 等微弱对比度图像时面临挑战，而现有的对称感知方法存在显著不足：部分方法采用全脑或全半球 attention 导致计算冗余，或局限于 2D 无法捕捉体积特征，更关键的是未校正头倾角直接对比镜像导致解剖对应关系错误，且难以适配 nnU-Net 的 patch 采样机制，同时缺乏跨模态及时间点的泛化评估与预测可靠性度量。

创新点

  • 提出两阶段 nnU-Net 兼容的 3D 分割 pipeline，通过显式的几何倾斜校正确保跨半球比较的解剖学有效性。
  • 设计 Asymmetric Feature Extraction (AsymFeX) 模块，结合 3D 局部跨半球 attention、feature disparity estimation 与 dual-scale gating，限制比较范围至局部邻域以降低计算成本。
  • 在 AISD 数据集上进行全面评估，包含消融实验、体积分析及临床相关性分析，验证方法在不同模态和卒中阶段的有效性。
  • 提供跨模态泛化证明与不确定性量化分析，评估模型在临床部署下的可靠性。
