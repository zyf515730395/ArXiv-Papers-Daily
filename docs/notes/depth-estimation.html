[2608.20788] M2Depth: Unifying Monocular Depth Foundation Priors with Multi-View Stereo

arXiv 原文

一句话结论

本文提出了 M2Depth 框架，通过双向相互精炼策略（bidirectional mutual refinement strategy）将深度基础模型（DFM）与级联多视图立体（MVS）流水线紧密耦合，利用 MVS 深度解决单目预测的尺度歧义性，同时利用单目深度增强 MVS 估计的结构完整性和细节，从而在标准基准上实现了超越现有最先进方法的多视图深度估计性能。

解决的问题

现有的多视图立体（MVS）方法在面对未见场景结构、复杂几何或遮挡区域时泛化能力不足，而近期将深度基础模型（DFM）引入 MVS 流水线的方法大多依赖静态的单向融合方案，无法充分挖掘两种模态的互补优势，导致 MVS 中心流水线在纹理缺失区域难以产生干净深度图，且 DFM 中心流水线缺乏显式多视图一致性，无法通过反馈机制动态补偿彼此的固有缺陷。

创新点

  • 提出通过双向相互精炼策略（bidirectional mutual refinement strategy）将深度基础模型（DFM）与级联多视图立体（MVS）流水线紧密耦合
  • 引入 prior-guided cost volume refinement mechanism，通过 attention-based fusion 和 discretized depth bins 有效整合多视图与单目信息
  • 利用 MVS 深度解决单目预测的尺度歧义性，同时利用单目深度增强 MVS 估计的结构完整性和细节

[2608.19769] AsymFeX: A Symmetry-Driven Framework for Ischemic Stroke Segmentation Across Imaging Modalities and Stroke Stages

arXiv 原文

一句话结论

本文提出 AsymFeX 框架，通过两阶段 nnU-Net 兼容的 3D 分割流程结合几何倾斜校正与局部跨半球 attention 机制，在非对比 NCCT 模态下实现急性缺血性卒中病变的高效精准分割，在 AISD 数据集上显著超越现有最先进方法并验证了跨模态泛化性与可靠性。

解决的问题

现有深度学习方法在处理非对比 NCCT 等微弱对比度图像时面临挑战，而现有的对称感知方法存在显著不足：部分方法采用全脑或全半球 attention 导致计算冗余，或局限于 2D 无法捕捉体积特征，更关键的是未校正头倾角直接对比镜像导致解剖对应关系错误，且难以适配 nnU-Net 的 patch 采样机制，同时缺乏跨模态及时间点的泛化评估与预测可靠性度量。

创新点

  • 提出两阶段 nnU-Net 兼容的 3D 分割 pipeline，通过显式的几何倾斜校正确保跨半球比较的解剖学有效性。
  • 设计 Asymmetric Feature Extraction (AsymFeX) 模块，结合 3D 局部跨半球 attention、feature disparity estimation 与 dual-scale gating，限制比较范围至局部邻域以降低计算成本。
  • 在 AISD 数据集上进行全面评估，包含消融实验、体积分析及临床相关性分析，验证方法在不同模态和卒中阶段的有效性。
  • 提供跨模态泛化证明与不确定性量化分析，评估模型在临床部署下的可靠性。

[2608.15659] WorldRover: A Scalable Synthetic Video Data Engine for World Exploration with Rich Annotations

arXiv 原文

一句话结论

本文提出 WorldRover 引擎与 WorldRover-10M 数据集，基于 Unreal Engine 合成管线生成富含 RGB、metric depth、相机轨迹及动作信号的长视界探索视频，将世界探索转化为可扩展的数据生成问题，为构建连贯世界表示的模型提供高质量监督数据。

解决的问题

可探索世界生成与 4D 重建要求模型在视角变化时保持场景一致性，但 RGB 数据导致视觉变化原因纠缠，难以区分相机运动与物体运动。真实视频采集虽覆盖广，但相机位姿和对应关系依赖后处理估计，存在漂移与遮挡失效风险；渲染虽能直接暴露场景状态，但现有合成资源多针对特定任务优化，缺乏在同一帧上结合 metric depth、相机轨迹与长程对应关系的综合数据，无法满足模型对场景一致性的监督需求。

创新点

  • 提出 WorldRover-Engine 离线渲染管线，在 Unreal Engine 中执行分钟级路线并完整保留轨迹与场景几何
  • 构建 WorldRover-10M 数据集，将 RGB 与 metric depth、相机轨迹及轨迹衍生的动作信号进行配对
  • 支持 first-person、third-person 及 360 panoramic 等多种视角下的渲染与环境状态变化
  • 提供 dense optical flow、长程 2D/3D point tracks 及独立于相机轨迹的角色轨迹作为额外标注
