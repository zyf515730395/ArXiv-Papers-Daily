[2608.23290] Spotter: Efficient Urban Visual Localization via Geo-Referenced Facade Landmarks in GPS-Degraded Environments

arXiv 原文

一句话结论

本文提出了 Spotter 框架，通过利用建筑立面作为可靠的地理参考并结合 GPS 信号，在 GPS 信号退化环境下实现了实时、高精度的城市视觉定位，性能优于里程计基线且帧率显著高于现有基于地图的方法。

解决的问题

现有视觉定位方法在密集城市环境中面临 GPS 信号因多径效应退化导致定位失效的问题，同时视觉里程计 (VO) 与视觉 SLAM 因增量式运动估计不可避免地产生无界漂移，而基于地图的图像定位方法虽能提供全局参考，但计算开销大且依赖不可靠的 GPS 先验来缩小搜索空间，难以满足轻量化平台实时边缘计算的需求。

创新点

  • 离线阶段利用 Google Street View 全景图，通过 semantic segmentation 立面并结合 multi-view stereo depth 与地图数据构建紧凑度量数据库
  • 运行时采用 cascaded retrieval and geometric verification pipeline，实现细粒度全局相机定位
  • 框架保留在可用时集成 GPS 信号的能力，且在 GPS 信号退化环境下保持鲁棒性
  • 在保持精度与现有基于地图方法相当的同时，实现了显著更高的帧率

arXiv 原文

一句话结论

解决的问题

现有的多视图立体（MVS）方法在面对未见场景结构、复杂几何或遮挡区域时泛化能力不足，而近期将深度基础模型（DFM）引入 MVS 流水线的方法大多依赖静态的单向融合方案，无法充分挖掘两种模态的互补优势，导致 MVS 中心流水线在纹理缺失区域难以产生干净深度图，且 DFM 中心流水线缺乏显式多视图一致性，无法通过反馈机制动态补偿彼此的固有缺陷。

创新点

  • 提出通过双向相互精炼策略（bidirectional mutual refinement strategy）将深度基础模型（DFM）与级联多视图立体（MVS）流水线紧密耦合
  • 引入 prior-guided cost volume refinement mechanism，通过 attention-based fusion 和 discretized depth bins 有效整合多视图与单目信息
  • 利用 MVS 深度解决单目预测的尺度歧义性，同时利用单目深度增强 MVS 估计的结构完整性和细节

[2608.19769] AsymFeX: A Symmetry-Driven Framework for Ischemic Stroke Segmentation Across Imaging Modalities and Stroke Stages

arXiv 原文

一句话结论

本文提出 AsymFeX 框架，通过两阶段 nnU-Net 兼容的 3D 分割流程结合几何倾斜校正与局部跨半球 attention 机制，在非对比 NCCT 模态下实现急性缺血性卒中病变的高效精准分割，在 AISD 数据集上显著超越现有最先进方法并验证了跨模态泛化性与可靠性。

解决的问题

现有深度学习方法在处理非对比 NCCT 等微弱对比度图像时面临挑战，而现有的对称感知方法存在显著不足：部分方法采用全脑或全半球 attention 导致计算冗余，或局限于 2D 无法捕捉体积特征，更关键的是未校正头倾角直接对比镜像导致解剖对应关系错误，且难以适配 nnU-Net 的 patch 采样机制，同时缺乏跨模态及时间点的泛化评估与预测可靠性度量。

创新点

  • 提出两阶段 nnU-Net 兼容的 3D 分割 pipeline，通过显式的几何倾斜校正确保跨半球比较的解剖学有效性。
  • 设计 Asymmetric Feature Extraction (AsymFeX) 模块，结合 3D 局部跨半球 attention、feature disparity estimation 与 dual-scale gating，限制比较范围至局部邻域以降低计算成本。
  • 在 AISD 数据集上进行全面评估，包含消融实验、体积分析及临床相关性分析，验证方法在不同模态和卒中阶段的有效性。
  • 提供跨模态泛化证明与不确定性量化分析，评估模型在临床部署下的可靠性。

一句话结论

解决的问题

创新点

  • 提出基于 MVS 稠密点云的预展平与法向对齐高斯初始化策略，将几何先验嵌入原语以减少弱观测区域的法向恢复歧义
  • 开发 PatchMatch-3DGS 双向监督机制，利用渲染深度和法向初始化 PatchMatch 并监督高斯优化，提供显式的深度级几何约束
  • 采用 Delaunay 图切割网格化管线替代 TSDF 体素融合进行表面提取，降低对体素分辨率的敏感性并提升室外场景的网格紧凑性

[2608.17832] GenRec: Knowing Where to Reconstruct and Where to Generate

arXiv 原文

一句话结论

GenRec 提出了一种多视角 flow matching 模型，通过观察掩码将重建与生成任务分离，在观测区域实现了最佳几何保真度，同时在未观测区域超越了纯生成基线，且推理速度比最强基线快两个数量级。

解决的问题

现有生成新视角合成方法将重建与生成混为单一统一损失，模糊了几何保真度与创意幻觉的界限，且传统 3D 场景表示如 NeRF 和 3D Gaussian Splatting 在稀疏输入下无法处理未观测区域。单一网络无法同时满足观测像素的唯一正确答案和未观测像素的可信补全需求，导致监督信号互相干扰。

创新点

  • 基于几何的生成新视角合成分解，使用每像素观察掩码对观测/未观测像素采用独立模块和损失。
  • 多视角 flow matching backbone 联合去噪 RGB 和 scene-coordinate maps，实现跨视角一致性与 3D 对应信号。
  • 像素空间重建分支利用 sparse 3D cross-attention 恢复潜在压缩丢失的细节，且不干扰未观测区域的生成先验。

一句话结论

  • 设计了度量深度解耦公式，基于现有单目深度基础模型的潜在表示学习每帧尺度误差，预测每个像素的深度不确定性和每帧的尺度不确定性。
  • 将上述概念整合为 Scalix 系统，实现了在大型环境中的 zero-shot 部署，并取得了最先进的度量级单目 SLAM 结果。

解决的问题

现有判别式单目深度估计方法常采用大 patch ViT 编码器与卷积上采样解码器组合，粗粒度分词（coarse tokenization）在编码阶段削弱了像素级线索与高频细节，导致卷积上采样难以完全恢复结构信息，进而产生几何失真；而像素空间生成式方法虽能保持细节但存在推理效率低下的矛盾。

创新点

  • 提出判别式架构，将全局上下文建模与像素级深度预测分离，利用大 patch ViT 捕捉全局场景上下文，同时通过像素空间预测器维持高分辨率空间表示。
  • 设计 Context-Modulated Pixel Transformer (CM-PiT) 模块，在深度估计过程中保持像素级空间特征的高分辨率表示。
  • 引入像素 - token 压缩机制（pixel-token compaction）以支持高效特征交互，避免全分辨率网格自注意力带来的计算开销。
  • 采用由粗到细的像素压缩设计，在平衡计算效率的同时确保细节几何的恢复。
