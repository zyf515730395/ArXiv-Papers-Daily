[2608.21229] Anchoring Instruction Outside Mask: Exact Reference Caching for Efficient In-Context Diffusion Transformers

arXiv 原文

一句话结论

本文提出锚定指令在掩码之外的超越掩码设计，结合两阶段蒸馏恢复性能，实现了多参考图像编辑中的高效上下文扩散生成，在保持全注意力质量的同时显著加速推理。

解决的问题

现有结构稀疏注意力方法虽能通过隔离参考图像 token 实现 K 和 V 的精确复用以降低计算成本，但阻断了视觉参考对文本指令的关注路径，导致多参考编辑场景下指令遵循能力和参考保真度显著下降，且单纯调整原有 token 序列的掩码无法兼顾缓存复用与信息交互的冲突。

创新点

  • 提出超越掩码设计，利用静态文本锚点连接指令与参考分支，在无需增加参数的情况下实现参考 K 和 V 的跨去噪步精确复用
  • 开发结合教师强制速度蒸馏与在策略蒸馏的两阶段恢复程序，首次将在线策略蒸馏应用于扩散模型的架构恢复以消除性能损失
  • 保持规则的注意力布局以兼容 FlashAttention 等高性能内核，确保实际加速效率
  • 该方法正交于其他扩散加速技术，原则上可与时间缓存等技术结合使用

[2608.20336] WithEveryone: Unified Planning and Identity Grounding for Group Image Generation

arXiv 原文

一句话结论

WithEveryone 提出了一种统一的框架，通过引入布局引导的身份损失和身份 - 布局规划，实现了包含多达十个指定身份的小组图像生成，在身份相似性和减少复制粘贴伪影方面优于现有模型。

解决的问题

现有方法主要处理少量人物（1-5 人），在生成大规模小组图像时身份相似度下降，且现有身份损失依赖生成图像中的面部嵌入匹配，在训练初期面部预测相似时匹配随意，导致监督失效和身份混淆，同时难以处理复杂的空间关系。

创新点

  • 提出交织的身份和布局推理，将参考身份作为 ID token 加载并结合结构化布局思维链进行联合预测。
  • 提出 Layout-Grounded ID Loss，利用布局标注直接监督身份而非依赖嵌入匹配，解决了现有损失无法扩展到多人的问题。
  • 引入 ID Representation Forcing，在图像合成前训练每个身份的预测表示，确保身份在共享上下文中可寻址。
  • 构建并评估了支持 5 到 10 人身份生成的系统，在身份不重叠基准上实现了更高的身份相似度和更低的复制粘贴伪影。

一句话结论

解决的问题

现有图像生成模型往往伴随着巨大的生成主干、昂贵的训练管道以及用于生成和编辑的分离模型变体，难以在有限计算预算下实现统一能力。紧凑模型对架构选择、任务失衡和不稳定训练尤为敏感，难以在单一权重下同时满足文本生成、单图及多图编辑等多种任务的多样化需求。

创新点

  • 构建了支持文本生成、单图及多图编辑的 6B 紧凑统一模型，在受限预算下实现领先性能。
  • 设计了涵盖渐进式训练、并行专家强化学习与多教师蒸馏的系统化训练流程。
  • 提出 Prompt Enhancer 将高层推理与像素级渲染解耦，提升复杂任务表现。
  • 通过结构剪枝和少步蒸馏实现模型压缩与加速，显著降低部署成本。
  • 总结了大规模训练中的架构、数据课程及后训练等可迁移实践。

  • 引入四字段结构化推理输出，配合前缀门控奖励和令牌级优势重加权，实现从结果级反馈到规划器局部监督的转化
