[2608.21008] Triangulation-Free Bundle Adjustment with Graduated Non-Convexity for Camera Pose Refinement from Coarse Priors

arXiv 原文

一句话结论

本文提出了一种无需三角化的 Bundle Adjustment 方法，结合 Graduated Non-Convexity (GNC)，在 CPU 上实现了低成本且鲁棒的相机位姿优化，不仅避免了传统方法对准确先验的损害，还显著扩展了收敛盆地以处理大幅度的先验误差。

解决的问题

现有 Mobile AR 框架（如 ARKit）提供的帧级度量先验位姿需经细化才能满足 NeRF 或 3D Gaussian Splatting 的精度要求，但主流流水线依赖三角化将先验误差固化到结构中，导致优化结果在 15 个 ScanNet++ 场景中全部退化。同时，经典 Bundle Adjustment 在超过 1-2 度先验误差时收敛盆地崩塌，而基于神经网络的细化方法则存在 GPU 小时级的计算开销。

创新点

  • 提出无需三角化的 Bundle Adjustment，每个关键点沿后投影射线拥有标量深度，移除轨道构建与三角化，结构在每次求解迭代中重新表达而非固定。
  • 引入 Graduated Non-Convexity (GNC) 机制，通过退火损失尺度平滑并逐步锐化成本景观，将收敛盆地扩展至 16 度/80 毫米误差，在 32 度误差下保持 85% 成功率。
  • 在单 CPU 上以每场景 10 秒的代价实现物体尺度 0.265 度/1.80 毫米的精度，且不损害准确先验，成功处理 330 次扰动房间运行。

[2608.20687] TopoSurfel: Closing the Loop between Gaussian Surfels and Meshes for Surface Reconstruction

arXiv 原文

一句话结论

论文提出 TopoSurfel 框架，通过引入无需 extra learnable parameters 的可微分代理网格，建立 Gaussian Surfels 与 continuous meshes 间的闭环优化，在保持 high-quality mesh-based novel view synthesis 的同时显著提升了 surface reconstruction 的几何精度并抑制了 artifacts。

解决的问题

现有的基于 3D Gaussian Splatting 的重建方法虽然在新视角合成上表现优异，但其 discrete 和 unstructured 的特性导致难以直接生成高质量 meshes，且缺乏 explicit structured geometric prior，容易在 textureless 或 occluded regions 产生 artifacts 和 floaters。此外，引入可微分 mesh 提取的方法往往依赖 costly local space partitioning，增加了计算和 memory cost，而 planar Gaussian representations 虽更接近真实 surface 但仍缺乏 explicit neighborhood connectivity，难以建立 continuous manifold 与 discrete Gaussian Surfels 之间的明确几何对应。

创新点

  • 提出 TopoSurfel 框架，利用非训练的可微分等值面过程动态提取 continuous proxy mesh，无需 extra learnable parameters 即可将 structured surface prior 引入 Gaussian Surfels 训练。
  • 设计 mesh-guided surfel evolution 策略，通过 normal alignment 和 geometry-aware density control，利用 explicit point-to-face distances 抑制 floaters 并填充 surface holes。
  • 引入 spatially aware hybrid re-initialization 策略，包含 stable warm-up stage 和 scene-aware re-initialization，确保在 large-scale environments 中的鲁棒重建。

[2608.20602] Sparse Light Field Sampling Improves Casual 3D and 4D Reconstruction

arXiv 原文

一句话结论

本文证明在固定传感器预算下，利用消费级多相机阵列进行稀疏光场采样能显著提升单拍及动态场景的 3DGS 和 4DGS 重建质量，且硬件增益可补充数据先验，提出了乘积光场相机原型以优化角空间权衡。

解决的问题

现有的新视角合成流水线通常仅使用单目流，依赖相机运动或学习先验来获取角覆盖，导致即使设备具备多相机（如智能手机），也只使用其中一个镜头进行训练；现有方法在积累角多样性时面临昂贵设备或角时分辨率权衡的矛盾，且对于动态场景，移动单目相机难以获得有效多视图线索，而学界普遍假设消费级相机基线过小无法提供有意义的视差线索。

创新点

  • 构建了包含 iPhone 15 Pro、Apple Vision Pro 和 Lytro Illum 三种消费级多视图相机的静态与动态真实世界数据集。
  • 建立了跨相机基准测试，系统评估了 3DGS、4DGS 及稀疏视图 Gaussian splatting 在不同相机类型、曝光数量和角基线下的重建质量。
  • 提出乘积光场相机原型，通过高分辨率子镜头图像在传感器上重叠，优化角空间权衡。
  • 实证发现消费级相机在视图受限场景下优于单目相机，且对于动态场景，时间步上的角多样性至关重要。

[2608.20534] Grounded-Exo2Ego: Structured Semantic Grounding for Robust Exocentric-to-Egocentric Video Generation

arXiv 原文

一句话结论

Grounded-Exo2Ego 提出了一种双分支视频 diffusion model 框架，通过结合几何锚定与 Semantic Grounding 分支，并引入相机重定位算法与合成数据引擎，解决了极视角变化下的几何条件不可靠与训练数据脆弱问题，在 EgoExo4D 数据集上显著优于现有 SOTA 方法。

解决的问题

现有的 exo-to-ego 视频生成方法主要依赖单目深度估计的 3D reconstruction 作为几何条件，但在极端视角变化下，monocular depth estimation 不准确会导致拉伸表面和错误位置，且大区域不可观测导致渲染出现扭曲和空洞。此外，单目重建与世界真实几何存在非刚性形变和尺度偏移，导致训练时 groundtruth 相机与重建严重错位，迫使大量样本被过滤，使得训练数据极其脆弱且现有方法仅靠几何条件无法保证质量。

创新点

  • 构建双分支视频 diffusion model，包含几何锚定分支与 Semantic Grounding 分支，结合 3D reconstruction 渲染与对象级语义上下文。
  • 引入相机重定位算法，解决 camera-reconstruction misalignment 问题，提升训练对齐质量。
  • 开发全自动合成数据引擎，用于生成和渲染 rigged 3D characters 及 procedural environments。
  • 超越 prevailing geometry-based approach，通过 Semantic Grounding 合成挑战性区域，解决遮挡和不可识别问题。

[2608.18593] ReX-Shot: Single-Image Rephotography via Geometry- and Camera-Grounded Generation

arXiv 原文

一句话结论

ReX-Shot 提出了首个统一框架，通过几何与相机基生成实现了单图像重摄影中视点、焦距及参数化摄影效果的联合控制，在各项控制维度上优于基线并支持近实时交互。

解决的问题

现有方法通常将视点、焦距和摄影效果控制视为独立子问题，忽视了它们的重摄影中的紧密耦合性。新视图合成在焦距变化下易引入几何畸变，而超分辨率和指令引导编辑局限于 2D 平面，无法可靠扩展到新视点，这源于单图像 3D 重建的 ill-posed 性质及连续焦距放大的采样限制。

创新点

  • 使用隐式转换的 foundation-model features 进行鲁棒的目标视图引导，以减少几何误差带来的投影偏差。
  • 将焦距放大形式化为 geometry-guided super-resolution 问题，利用生成式细节先验恢复稀疏 3D 重采样中丢失的细节。
  • 将摄影效果控制从 2D filtering 提升为 3D-aware appearance editing，确保跨视点和焦距的内容一致性。
  • 构建了首个统一框架，实现单图像重摄影中 viewpoint、focal length 和 parameterized photographic effects 的联合控制。
