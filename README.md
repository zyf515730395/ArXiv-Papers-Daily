# Arxiv Papers Daily

A focused daily archive of computer vision papers from arXiv.

[Arxiv Papers Daily](https://zyf515730395.github.io/arxiv-papers-daily/)

## Topics

- Image Generation
- Video Generation
- 3D Generation
- Neural Rendering
- Depth Estimation

The public repository contains the cloud-side arXiv collection, archive,
site-generation and GitHub Pages deployment code, plus sanitized summary HTML
generated by the local scheduler. Local paper review and inference code, model
configuration, Markdown notes, state files and machine-specific automation are
excluded from version control.
